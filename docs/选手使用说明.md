# 选手使用说明

塔大网安师市行 CTF-AWD 实战平台 · 选手端

## 1. 登录与加入队伍

1. 打开平台地址 `https://<比赛域名或IP>`，进入登录页。
2. 已有账号：输入用户名和密码，点击「登录平台」。
3. 没有账号：切换到「邀请码注册」，填写用户名、密码（至少 8 位）和队伍邀请码。邀请码由管理员发放，格式如 `TARC-01-2026`。
4. 注册成功即自动加入对应队伍。每队最多 4 名选手，队伍满员后邀请码不可再用；同一选手只能属于一支队伍。

忘记密码或需要换队：请联系统一处理，选手无法自行修改队伍归属。

## 2. 训练首页（/dashboard）

登录后首先看到本队战况：

- **本队当前总分**：墨色面板上的大号数字，含当前排名、有效攻击次数、被攻击次数和比赛剩余时间。
- **提交 Flag**：输入框 + 「提交验判」按钮，是选手最常用的操作。
- **下一轮 Flag**：倒计时显示本轮 Flag 还有多久轮换。轮换周期默认 300 秒，上一周期 Flag 有 30 秒提交宽限。
- **本队服务**：三个服务的运行状态。出现「服务异常」「恢复中」要尽快处理。
- **最新公告**：管理员发布的比赛通知。
- **当前排名**：前五名预览，完整榜单在计分板页。

## 3. 提交 Flag 与计分规则

在首页或「提交记录」页输入从其他队伍服务中拿到的 Flag（格式 `flag{...}`）并提交：

| 结果 | 含义 | 分数变化 |
|---|---|---|
| 有效攻击 | 首次提交其他队当前有效 Flag | 本队 +100，对方 -50 |
| 重复提交 | 本队已交过同一个 Flag | 无变化 |
| 本队 Flag | 提交了自己队伍的 Flag | 无变化 |
| 已过期 | Flag 超出有效期或宽限期 | 无变化 |
| 无效 Flag | Flag 不存在或格式错误 | 无变化 |
| 比赛未进行 | 比赛暂停或已结束 | 无变化 |

要点：

- 不同队伍可以分别提交同一个有效 Flag，各自 +100，防守方每次 -50。
- 提交后立即显示双方分数变化；计分板最迟 5 秒更新。
- 总分允许为负，不做清零。
- 同一 Flag 每轮都不同，拿到后尽快提交，300 秒后轮换。

## 4. 实时计分板（/scoreboard）

- 展示全部队伍的排名、总分、有效攻击、被攻击、每个服务的状态和最后得分时间。
- 支持按队名或编号搜索。
- 计分板被冻结时显示黄色提示条：前台停留在冻结时刻快照，后台仍在正常计分，比赛结束后以流水为准。
- 「同分排名」规则见页面底部说明。

## 5. 我的靶机（/targets）

本队每个服务一行，包含：

- **比赛入口**：`<服务器地址>:<公网端口>`，这是其他队伍攻击你的入口，点击复制按钮可快速复制。端口规则为 `20000 + 队伍编号 × 100 + 服务编号`。
- **状态**：运行正常 / 服务异常 / 恢复中 / 待人工处理。
- **终端**：打开本队 Web 终端（浏览器内 SSH），仅能访问本队管理网关，可用于修补漏洞、部署补丁。
- **重启**：确认后保留数据卷重启本队服务，不会清除你的补丁。

注意：

- 你只能看到和管理本队的靶机；访问其他队伍只能在比赛端口上攻击其服务。
- 被打穿后第一时间通过终端修漏洞、换口令，再视情况重启服务。
- 连续两次健康检查失败会触发平台自动重启；5 分钟内最多自动重启两次，超过后转人工处理。

## 6. 提交记录（/submissions）

- 按时间倒序显示本队每次提交的验判结果、目标队伍、双方分数变化和请求 ID。
- 可按验判结果筛选（如只看有效攻击）。
- 平台日志只保存 Flag 哈希，不记录明文。

## 7. 公告（/announcements）

管理员发布的比赛通知：时间调整、服务异常、纪律提醒等，置顶公告显示在最上方。重要公告会实时推送，请保持页面开启。

## 8. 比赛纪律（必读）

- 仅允许攻击已开放的比赛端口，禁止访问宿主机管理接口、云元数据地址（169.254.169.254）和其他队伍管理网。
- 禁止对平台本身（登录、计分、计分板）进行攻击或刷分尝试。
- 禁止删除、破坏其他队伍数据卷中的非比赛数据。
- 所有登录、提交、终端操作均有审计记录。
- 违规操作由管理员按训练纪律处理，必要时取消成绩。

## 9. 常见问题

**提交提示「比赛未进行」？** 比赛处于暂停或已结束，等待管理员恢复。

**Flag 明明是对的却提示已过期？** 每轮 Flag 有效期约 300 秒 + 30 秒宽限，过期后需重新获取当轮 Flag。

**终端连不上？** 先确认本队靶机状态为运行正常；重启一次仍不行请联系管理员。

**看到本队分数变少？** 表示有队伍提交了你们的 Flag，尽快定位并修复漏洞。
